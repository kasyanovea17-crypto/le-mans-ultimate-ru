# Le Mans Ultimate — русский перевод

**Ле-Ман. На твоём языке.** Неофициальный перевод меню и настроек с Windows-лаунчером от Karsvein.

[Скачать лаунчер](https://github.com/kasyanovea17-crypto/le-mans-ultimate-ru/releases)

![Лаунчер](docs/launcher-preview.png)

## В этом выпуске

- **2 386** обработанных строк: **2 357** с русским текстом и **29** технических обозначений, брендов и служебных шаблонов.
- Перевод меню, настроек и подсказок из двух словарей интерфейса.
- Пять открытых шрифтов Roboto / Roboto Condensed с кириллицей.
- Поиск установленной игры Steam, проверка совместимости, установка, восстановление оригинала и запуск через Steam.
- Все ресурсы встроены в EXE; Python и Node.js для установки не нужны.

**Гоночный HUD в этот публичный выпуск не входит.** Надписи внутри рекламных изображений и серверный контент также не переводятся этим пакетом.

## Установка

1. Скачайте ZIP из Releases и распакуйте его в отдельную папку.
2. Закройте игру и откройте `LMU-RU-Launcher.exe`.
3. Проверьте папку игры, нажмите **Проверить файлы**, затем **Установить перевод**.
4. Оставьте язык игры **English**: перевод занимает английский языковой слот.
5. Запустите игру кнопкой лаунчера.

Поддерживается проверенная сборка **Le Mans Ultimate 1.4150**. Требуются Windows x64, .NET Framework 4.8 и около 3 ГБ свободного места. Для записи в Program Files может потребоваться подтверждение Windows. Лаунчер не подписан цифровым сертификатом.

## Восстановление

Кнопка **Восстановить оригинал** возвращает исходный `Bin/UI.zip` побайтно. Резервная копия остаётся в `Bin/LMU-RU-backup/UI.original.zip`. Сохранения, профиль и настройки управления не изменяются.

Если ранее устанавливался пробный перевод, выберите **Указать исходный UI.zip** и импортируйте сохранённый оригинал. Повреждённая или чужая копия не принимается. После обновления Steam заново проверьте совместимость — неизвестный архив не перезаписывается.

## Исходники и проверки

```powershell
.\build.ps1 -Test
.\build\EngineTests.exe --real "D:\Original\UI.zip" "D:\LMU-test-game"
```

Второй тест работает только с новой отдельной папкой. Он проверяет установку, восстановление и повторную установку; EXE-маркер фикстуры не запускается. Результат сборки — `build/LMU-RU-Launcher.exe`.

[Результаты проверок](docs/TEST_RESULTS.md)

- Исходный SHA-256 UI.zip: `7456925e14e4433045cfb67f866d5716c25ea02d9f34c1ea06156ede5b21aa96`.
- Перед заменой проверяются резервная копия и каждый изменяемый ресурс.
- Все остальные записи архива сравниваются с оригиналом по SHA-256.
- Файл заменяется атомарно. Работающая игра блокирует установку и откат.
- Пакет содержит перевод, открытые шрифты и короткие правила изменения CSS/JavaScript, **не полный игровой архив или игровые EXE**.
- Проверка меню не является проверкой всех сетевых режимов и устройств.
